| Encontro | Tema | Materiais |
|---:|---|---|
| 1 | Apresentação, POO e história do Java | [Abrir](encontros/encontro-01/) |

Cada pasta contém a apresentação em Markdown, o material do aluno e os exemplos necessários para a prática. O deck completo do Encontro 3 também está disponível no [Gamma](https://gamma.app/docs/op065whc053zb46).

## Requisitos gerais

- JDK LTS adotado pela turma;
- Visual Studio Code ou outro editor;
- terminal;
- Git para registrar as versões locais.

Os exemplos foram planejados para funcionar sem conexão com a Internet depois de baixados.

## O que não está neste repositório

Guias do professor, gabaritos, registros internos, rubricas e versões de preparação permanecem fora do material público dos estudantes.
