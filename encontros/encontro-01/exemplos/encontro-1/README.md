# Exemplo do encontro 1

## Requisitos

- JDK LTS adotado pela turma;
- terminal;
- Visual Studio Code é recomendado, mas não é obrigatório.

## Compilar e executar

~~~text
javac PrimeiroPrograma.java
java PrimeiroPrograma
~~~

Saída esperada:

~~~text
Olá, Java!
Meu primeiro programa da disciplina.
~~~

## Verificar a instalação

~~~text
java --version
javac --version
~~~

Os números exatos dependem do JDK LTS definido para o semestre.

## Alternativa sem Internet

O exemplo não depende de Internet. Se o GitHub estiver indisponível, conclua compilação, execução e commit localmente e faça o push posteriormente.
